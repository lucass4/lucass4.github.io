{{/* Sequence diagram as semantic HTML, for showing how a request moves through a system and where it is stopped. Usage: {{< flow caption="..." label="..." >}} Step name :: what happens gate: Boundary name :: what it refuses {{< /flow >}} A line prefixed `gate:` renders as a boundary rather than a step, because in an agent the interesting part is not the happy path, it is where the path is interrupted. Steps are numbered; gates are not, so the numbering counts work and not checkpoints. Same reasoning as the `stack` shortcode: HTML rather than an SVG, so it reflows at 390px, follows the theme tokens, stays selectable and is read in order by a screen reader. */}} {{- $rows := slice -}} {{- range split (trim .Inner "\n ") "\n" -}} {{- $line := trim . " \t" -}} {{- with $line -}} {{- $isGate := hasPrefix (lower $line) "gate:" -}} {{- $body := $line -}} {{- if $isGate }}{{ $body = trim (substr $line 5) " " }}{{ end -}} {{- $parts := split $body "::" -}} {{- $rows = $rows | append (dict "gate" $isGate "name" (trim (index $parts 0) " ") "detail" (cond (gt (len $parts) 1) (trim (index $parts 1) " ") "") ) -}} {{- end -}} {{- end -}} {{- $id := printf "flow-%s" (substr (sha1 .Inner) 0 8) -}}
